# Portfolio images

Image ko sahi folder mein upload karein, baqi sab automatic hai:

- `thumbnails/`    -> Thumbnails
- `logos/`         -> Logos
- `social-media/`  -> Social Media & Posts
- `other/`         -> Other

Formats: JPG, JPEG, PNG, WebP.
Upload ke 1-2 minute baad GitHub Action `manifest.json` update kar deta hai aur image website par aa jati hai.
Image delete karne par bhi wohi hota hai: delete karein, commit karein, gallery se hat jati hai.
Same image dobara upload karein to sirf ek baar dikhti hai.
